# 🧫 Bacterial Growth: Interactive Math Lesson

Welcome to the **Bacterial Growth Interactive Lesson**! 

Have you ever wondered how a tiny group of bacteria can multiply into millions in just a few hours? This project is a simple, interactive website that explains the math behind how populations grow. It is designed to be easy to understand, even if you are not a math expert!

## 📖 What is this?

This web page walks you through two real-world mathematical models:
1. **Exponential Growth**: What happens when bacteria have unlimited food and space? (Spoiler: They grow incredibly fast).
2. **Logistic Growth**: What happens in real life when bacteria eventually run out of food and space? (The population levels off and stops growing).

## ✨ Features

* **Interactive Graphs**: Type in different numbers (like starting population or growth rate) and watch the charts update instantly in real-time!
* **Live Math Calculations**: Pick a specific time (like 30 hours from now) and the website will calculate exactly how many bacteria there are.
* **Beautiful Math Formulas**: The complex math equations are beautifully written out using a tool called KaTeX.
* **Two Themes**: Click the sun/moon switch in the top right corner to swap between a vintage "Aged Paper" look and a sleek "Dark Mode".
* **Mobile Friendly**: Works great on your computer, tablet, or phone.

## 🚀 How to Use It

The best part? **Zero installation required.** You do not need to download any special software or run any servers.

1. Download or clone this repository to your computer.
2. Open the folder.
3. Double-click on **`index.html`** or **`quick-view.html`** to open it directly in your web browser (like Chrome, Safari, or Edge).
4. Read the lesson, play with the numbers, and watch the graphs change!

*Note: `quick-view.html` is a special file that has the entire lesson packed into one single file. It's great if you just want to quickly share the project with a friend.*

## 📁 Project Structure

If you want to look at the code, here is how everything is organized:

* `index.html` - The starting point that sends you to the main lesson.
* `quick-view.html` - A standalone, all-in-one version of the lesson.
* `HTML/main.html` - The main file containing the text and layout of the lesson.
* `CSS/style.css` - The design file that makes everything look pretty and handles the Dark/Light themes.
* `JS/script.js` - The brain of the project. It does all the math and draws the charts.

## 🛠️ Technologies Used

Built with simple, standard web tools:
* **HTML, CSS, and JavaScript**
* **Chart.js**: A free tool used to draw the interactive graphs.
* **KaTeX**: A free tool used to display the math formulas nicely on the screen.
